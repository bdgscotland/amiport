## Description

Find printable strings in binary files. Scans files for sequences of printable characters of a given minimum length (default 4). Supports offset display in decimal, octal, or hex.

## Prior Art on Aminet

Old implementations exist (jffabre Unix commands collection ~1995, Geek Gadgets binutils ~1998) but both are 25+ years old with no recent maintenance. This is a fresh, lightweight, standalone implementation.
