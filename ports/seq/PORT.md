## Description

Print sequences of numbers. Supports custom separators, format strings, and fixed-width zero-padded output. Useful for shell scripting loops and generating numbered lists.

## Prior Art on Aminet

No standalone seq utility found on Aminet. The jot port (already in amiport) provides similar but not identical functionality.
