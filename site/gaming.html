amiport gaming

Classic PC games, running on your Amiga.

Ten game ports unified into one portal. Doom, Caesar III, Celeste, Master of Orion, Prince of Persia, Command & Conquer -- compiled with bebbo-gcc, riding on libSDL2-amigaos3, installable with amiport install amiport-gaming.

Browse ports Request a game
Install the gaming meta-package
1.SYS:> amiport install amiport-gaming
1.SYS:> amiport-gaming list --playable

The meta-package pulls libSDL2-amigaos3 (0.7.0+) and SDL2_mixer, and installs launchers to SYS:Games/. Game data files are not included -- see each port for legal acquisition.
