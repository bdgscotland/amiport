Catalog > POSIX Shims
What is this?

amiport provides a POSIX compatibility shim library that maps Unix system calls to AmigaOS equivalents. This page shows which functions are missing and how many porting candidates each one would unlock. Implementing a high-unlock function makes more tools portable at once.

Bundled Libraries

Beyond the POSIX shim, amiport ports entire third-party libraries and ships them as static archives. Ports link against these to get capabilities AmigaOS does not provide natively. All built for 68k with bebbo-gcc, audited for memory safety and 68k-specific hazards.
